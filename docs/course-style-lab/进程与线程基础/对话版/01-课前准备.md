# 进程与线程基础｜课前准备

> 版本：V0.4（对话式教学）  
> 本节关键词：程序、进程、PCB、线程、资源共享、上下文切换。

## 从我们每天都在用的浏览器说起

**老师：** 我们先想一个每天都可能遇到的场景：浏览器里开着十几个网页，视频正在播放，文件也在下载，这时我们还能继续点开新页面。屏幕上看起来只是一个浏览器，背后是不是只有一件事在做？

**学生：** 显然不是。播放、下载和打开页面都在往前推进。

**老师：** 对。站在操作系统的角度，我们可以先把它画成这样：

```text
磁盘里的浏览器文件
    ↓ 双击启动
浏览器进程
    ├─ 界面线程：负责响应你的点击
    ├─ 网络线程：负责接收网页和下载数据
    └─ 渲染线程：负责把内容显示到页面上
```

**老师：** 顺着这张图，我们先提出几个实际问题：

- 浏览器安静地躺在磁盘里，和它真正运行起来，有什么区别？
- 浏览器占用的内存、打开的文件和网络连接，由谁统一管理？
- 下载文件时页面还能正常操作，这些任务是怎么一起推进的？
- CPU 执行到一半去处理别的任务，回来后怎么知道刚才做到哪了？

**学生：** 这些问题是不是分别对应程序、进程、线程和切换？

**老师：** 正是。我们先让这些关键词逐个登场。

## 程序：还没跑起来的那份代码

**老师：** **程序**是保存在磁盘等介质上的指令和数据。你可以把它想成什么？

**学生：** 像一份菜谱？步骤已经写好，但厨师还没动手。

**老师：** 很合适。厨房里还没有正在进行的烹饪过程。磁盘里的浏览器可执行文件就是程序，它说明浏览器可以做什么，此时还没有自己的运行状态。

## 进程：程序真正跑起来后的这一趟

**老师：** 那双击浏览器图标以后发生了什么？

**学生：** 操作系统把程序加载起来，给它安排地址空间、内存和文件等资源。

**老师：** 对，此时产生的一次运行，就是**进程**。程序和进程有点像“游戏安装包”和“这一局正在进行的游戏”。安装包可以反复启动，每启动一次，都可能形成一个新的运行实例。

**学生：** 所以同一款编辑器启动两次，系统也可能创建两个进程。它们代码相同，但运行状态和资源环境各自保留。

**老师：** 没错，不能因为程序代码相同，就把两次运行当成同一个进程。

## PCB：操作系统给进程建的档案

**老师：** 电脑同时运行很多进程，操作系统能靠“我好像见过它”来管理吗？

**学生：** 不能，得给每个进程留一份可以查询和修改的记录。

**老师：** 这份管理记录就是 **PCB（进程控制块）**。PCB 通常记录：

- 这是哪个进程：进程标识；
- 它现在是什么状态：进程状态和调度信息；
- 它刚才执行到哪里：程序计数器和寄存器现场；
- 它正在使用什么：内存、进程级打开文件资源等信息。

**学生：** 进程被暂停后还能接着运行，也靠这份记录吗？

**老师：** 对。操作系统先保存必要信息，进程再次获得 CPU 时，再根据这些信息从原来的位置继续。就像游戏先存档，之后才能接着玩。

**学生：** 那教材说“PCB 是进程存在的唯一标志”，是在说操作系统通过 PCB 识别和管理进程。

**老师：** 理解得很准确。

## 线程：进程里的任务执行线

**老师：** 回到浏览器。它既要响应点击，又要加载网页，还可能在后台下载文件。如果所有任务排成一条长队，会怎样？

**学生：** 下载稍微卡一下，整个浏览器可能都得跟着等。

**老师：** 所以需要**线程**。线程是进程内部的一条执行线。一个进程至少有一条线程，也可以安排多条线程分别推进不同任务。

**学生：** 放到浏览器里，界面响应、网络加载和页面渲染可以由不同线程推进。即使网络加载暂时等待，界面线程仍有机会响应操作。

**老师：** 对，这就是多条执行线带来的作用。

## 资源共享：同一进程里的线程可以共用哪些资源

**老师：** 这些线程属于同一个进程，通常可以共享什么？

**学生：** 地址空间和程序代码，全局变量、静态数据和堆，还有进程级打开文件资源。

**老师：** 例如，下载线程更新进度数据，界面线程可以直接读取并刷新进度条，不需要各准备一份副本。但共享是不是只有方便、没有代价？

**学生：** 不是。两条线程同时修改同一份数据，就像两个人同时改一张订单，可能谁也说不清哪一版才对。

**老师：** 对。后面学同步互斥时，我们会专门处理这个问题。

## 上下文切换：CPU 换人干活前要先记住进度

**老师：** CPU 不会永远只执行一个任务。它从当前任务切到另一个任务前，要做什么？

**学生：** 先保存当前任务的运行信息，再恢复下一个任务的运行信息。

**老师：** 这就是**上下文切换**。像我们写作业时临时接电话，离开前最好记住做到哪一步，回来才能接着写。

**学生：** 同一进程里的线程共享地址空间，所以切换时通常主要处理线程自己的程序计数器、寄存器和栈；跨进程切换还可能更换地址空间和内存管理上下文。因此，同进程线程切换通常更轻。

**老师：** 但“更轻”是不是等于没有开销？

**学生：** 不是。只要换了执行对象，保存和恢复现场的工作就少不了。

## 这些词先混个脸熟，别急着背

**老师：** 到这里，我们只需要先知道这些词大概在说什么。真正容易绕晕的是：进程和线程为什么要同时存在，一个负责什么，另一个又负责什么，它们在同一个应用里怎么配合。
