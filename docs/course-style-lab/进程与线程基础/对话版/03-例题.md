**老师：** 上一节我们留下了三个判断动作，还记得吗？

**学生：** 找进程、找线程、看切换范围。

**老师：** 对。下面把浏览器换成下载器，用这三步处理一个完整场景。

## 主例题：一个下载器怎样同时完成多项工作

### 场景

**老师：** 磁盘中保存着下载器程序 `downloader.exe`。用户启动程序后，系统创建进程 P。P 内有三条线程：

- T1：接收网络数据；
- T2：把数据写入文件；
- T3：更新界面上的下载进度。

运行过程中，CPU 先从 T1 切换到 T3，之后又从 P 的某条线程切换到另一个浏览器进程 Q。

### 问题 1：程序、进程和线程分别是谁

**老师：** 先别想复杂，按“磁盘文件—运行实例—内部任务”来分。磁盘里的 `downloader.exe` 是什么？

**学生：** 它还没运行，是**程序**。P 是程序启动后形成的**进程**，负责这次运行的资源环境；T1、T2、T3 是 P 里的**线程**，分别执行接收、写入和更新界面的任务。

**老师：** 所以我们得到什么关系？

**学生：** 一个程序可以启动出多个进程，一个进程里也可以有多条线程。

### 问题 2：操作系统怎样暂停并恢复 P

**老师：** P 被切走后还得接着运行，系统至少要解决什么问题？

**学生：** 要记住它停在哪里、当前是什么状态。PCB 会保存管理信息，例如：

- 进程标识；
- 进程状态和调度信息；
- 程序计数器和寄存器现场；
- 内存及进程级打开文件资源等信息。

**老师：** 可以把它理解成“先存档，再读档”：切出 P 时保存现场，再次调度 P 时恢复现场，它就能从原来的位置接着执行。

### 问题 3：T1、T2、T3 共享什么，各自保留什么

**老师：** 我们先把答案放进表格：

| 通常共享 | 通常各自保留 |
| --- | --- |
| 地址空间、程序代码 | 程序计数器 |
| 全局变量、堆 | CPU 寄存器现场 |
| 进程级打开文件资源 | 线程栈、线程 ID、线程状态 |

**学生：** 判断标准就是：属于整个下载器进程的资源，三条线程可以共用；记录某条线程执行到哪里的内容，必须各自保存。

**老师：** 对。共享方便协作，但如果它们同时修改共享数据，也可能发生冲突。

### 问题 4：两次切换哪一次通常更轻

**老师：** 先比较切换范围。T1 → T3 跨进程了吗？

**学生：** 没有。两条线程属于同一进程，共享地址空间，通常重点切换线程执行现场。

**老师：** P → Q 呢？

**学生：** 跨越两个进程，还可能更换地址空间和内存管理上下文。

**老师：** 因此，T1 切换到 T3 通常更轻，因为它们还在同一个地址空间里。切到 Q 时跨了进程，系统可能还要更换地址空间和内存管理上下文。但别误解成同进程线程切换没有开销。

**学生：** 两种切换都要保存和恢复现场，区别只是通常要处理的内容多少不同。

## 变式 1：同一个程序能形成几个进程

### 题目

**老师：** 用户把同一个代码编辑器启动两次，系统创建两个不同 PID，二者分别拥有独立的地址空间。它们属于一个进程还是两个进程？

### 答案

**学生：** **两个进程。** 虽然运行的是同一份程序代码，但系统给了它们不同 PID 和独立地址空间，说明这是两个独立管理的运行实例。

**老师：** 对，不能只看代码是否相同，还要看是不是独立的运行实例。

---

## 变式 2：共享变量一定能得到正确结果吗

### 题目

**老师：** 线程 T1 和 T2 共享全局变量 `count`。初始值为 0，两条线程都执行一次 `count = count + 1`。最终结果一定为 2 吗？

### 答案

**学生：** 看起来两次加一，应该是 2？

**老师：** 这里容易忽略执行步骤。`count = count + 1` 通常要经历读取、计算、写回。假如 T1、T2 都先读到 0，再各自写回 1，结果会是多少？

**学生：** 最后是 1。所以答案是**不一定**，这里丢掉了一次更新，共享数据并不自动保证结果正确。

## 变式 3：找出错误并改正

### 题目

**老师：** 判断这句话：“同一进程内的线程共享地址空间，所以它们也共享程序计数器和线程栈。线程切换不需要保存现场。”

### 答案

**学生：** **这句话错在把“共享资源”和“各自的执行现场”混到了一起。** 同一进程内的线程通常共享地址空间；程序计数器、寄存器和线程栈记录的是每条线程自己的执行过程，需要分别保存。线程切换时这些现场仍要保存和恢复，所以开销不会消失。

**老师：** 很好，先按资源归属分类，就不会被“都在同一进程”带偏。
