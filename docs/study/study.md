# study/ 学习文档库总文档

> 本库服务于"人借项目学习 Python 全栈"：不追求 AI 喂知识，而是引导人在真实项目中
> 建立通透认知。规则见 `../docs.md` §7。

## 结构与分工

| 文件夹 | 放什么 | 谁写 |
|---|---|---|
| `guide/` | 学习方法论与路线图（怎么学、学到什么算过关） | AI 编写，人使用 |
| `patterns/` | 概念→项目实例对照：一篇一个 Python/Web 概念，落到本项目真实代码 | 人提问驱动，AI 起草 |
| `log/` | 学习笔记与心得（我学了什么、卡在哪、想通了什么） | **人执笔为主**，AI 可应要求协同整理 |

## patterns/ 写作模板

```markdown
# <概念名>（如：依赖注入）
## 概念是什么（通俗+严谨各一段）
## 在本项目中的实例（文件/函数/代码片段，给锚点）
## 为什么这里用它（不用会怎样）
## 延伸问题（可选）
```

已登记概念：（暂无——第一个来了就补，如 SSE、中间件、生产者消费者、fencing token、拓扑排序）

## 学习 log 写作建议

一天一文件 `YYYY-MM-DD.md`，只记三样：今天学了什么域/链路、卡壳与想通的地方、
明天打算学什么。AI 的开发日志在 `../project/log/`，两边不混写。
