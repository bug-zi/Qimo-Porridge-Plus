# log/ 开发日志

AI 维护的开发日志：记录项目开发情况，每天一个 `YYMMDD.md`。

**使用方式**：

- 文件名 `YYMMDD.md`（如 260924.md）；同日多会话用二级标题追加（`## 会话 N：主题`）。
- 每个二级标题（会话小节）下首行附创建时间：`> 创建于 YYYY-MM-DD HH:MM`（date 命令实取，不估不编）。
- append-only：写完不改，勘误在当日文末补记，不删原文。
- AI 在每个有实质工作的会话结束时必写（与更新 DEV_BOARD 同级义务）。
- 小节结构：标题（功能名 + 来源 + 范围）→ 需求 → 设计定稿（含 spec 路径）→ 实施 → 验证 → 涉及文件。
- 记什么：做了什么 / 关键决策及理由 / 发现的问题 / 设计异议 / 下一步。不记流水账。

**边界**：学习侧日志在 `../study/log/`（保持 `YYYY-MM-DD.md` 命名），两边不混写。
