# 划词删除反馈只显示提交成功，无删除预览/确认
- 档案号：2026-08-28-selection-delete-feedback-preview
- 发现时间：2026-08-28（用户反馈）
- 严重度：高
- 所属域：modules/course-feedback
- 发现场景：课程划词选择"删去"意图提交反馈
- 错误现象：只显示提交成功，无删除预览与确认步骤
- 导致后果：用户无法预知删除效果，信任感差
- 根因：删除意图未补"删去"关键词；rewriteError 未按部分成功处理、不支持原 feedbackId 重试
- 建议修复方式：删除意图补"删去"；部分成功+原 id 重试；删除显示结构化预览与确认
- 状态：✅ 已关闭（2026-08-28）
- 关联：看板；course_feedback_service.py
