# 300s 总超时误杀思考型慢请求
- 档案号：2026-08-28-request-timeout-misjudge
- 发现时间：2026-08-28
- 严重度：中
- 所属域：core/model-client
- 发现场景：思考型模型正常长时间生成
- 错误现象：正常慢请求被 300s 超时杀掉，重试再杀，假死循环
- 导致后果：生成反复失败，模型费用浪费
- 根因：非流式等待下超时参数两难（CLAUDE.md 架构债记载）
- 建议修复方式：改流式 + 首 token 超时（30s 无首字节判死），读流阶段不误杀
- 状态：✅ 已关闭（阶段1）
- 关联：model-client 域 design.md 决策2；MODEL_REQUEST_TIMEOUT_SECONDS 处注释
