# 80 分课程生成 Prompt｜对话版

> 状态：正式风格模板  
> 风格 ID：`dialogue`  
> 用途：课程初始化选择“对话版”后，由后端模板注册表确定性注入课程 Prompt。

## 核心表达方式

采用老师与一名或多名学生的教学对话推进“课前准备、讲解、例题、自测”四份课程内容。

每轮对话必须承担至少一项教学功能：

1. 老师提出能推动理解的问题；
2. 学生尝试判断并展示真实思路；
3. 老师定位决定答案的条件；
4. 对典型误区进行澄清；
5. 从当前结论自然引入下一概念。

## 对话边界

- 删除寒暄、表演性互动和无信息回应；
- 老师不连续灌输长段定义；
- 学生不机械复述老师刚讲过的话；
- 对话中的口语表达必须准确落回标准术语；
- 角色名称保持稳定；
- 连续多轮只更换说话人但没有新增信息时，合并或删除；
- 资料事实、考试范围和当前任务合同始终高于对话效果。

## 四份文档分工

### 01-课前准备

用具体场景触发师生之间的第一组真实问题，建立关键词和基本关系，不提前复制完整讲解。

### 02-讲解

通过“提问—尝试判断—指出条件—澄清误区”的对话沿因果线推进。每个概念只落一次结论，小结转化为可执行判断方法。

### 03-例题

老师可逐步追问，学生先尝试判断，随后共同找出决定答案的条件。保留一个主例题和独立变式，答案必须完整。

### 04-自测

脱离老师提示，让学生独立作答。参考答案可使用简短讲评口吻，但不能继续代替学生完成推理。

## 通用质量要求

- 只使用资料支持的知识，宁可少生成，也不硬凑知识点；
- 禁用“不是……而是……”及机械变体；
- 删除无信息安抚、目录播报和重复结论；
- 01→02 从问题进入解释，02→03 从方法进入示范，03→04 从带练进入独立判断；
- 语言亲切、直接，每句话提供事实、解释原因、限定边界或推进理解。
