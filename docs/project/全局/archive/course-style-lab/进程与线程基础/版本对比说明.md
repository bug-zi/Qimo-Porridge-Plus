# 进程与线程基础｜三种课程形式对比

> 当前比较结论：用户认为**故事版效果最好**，故事版确认为当前优选形式。

本目录提供三套内容范围一致、表达形式不同的课程文档，方便逐份对照阅读。

## 目录

| 版本 | 表达方式 | 适合重点观察 |
| --- | --- | --- |
| [标准版](./标准版/) | 学长式、直接讲解 | 信息密度、逻辑清晰度、阅读效率 |
| [对话版](./对话版/) | 老师与学生问答推进 | 亲和力、疑问承接、误区澄清 |
| [故事版](./故事版/) | 连续故事承载概念和练习 | 代入感、阅读动力、知识记忆 |

每个版本均包含：

1. **课前准备**：建立场景和关键词基础；
2. **讲解**：解释进程、线程、PCB、资源共享与切换开销；
3. **例题**：一个主场景加三道变式；
4. **自测**：五道客观题加两道场景简答，并附参考答案。

## 建议比较方式

按同一模块横向阅读，而不是先完整读完某一个版本：

1. 对比三版的“01-课前准备”，判断哪一版最容易让人愿意继续读；
2. 对比三版的“02-讲解”，判断哪一版最容易理解因果和概念关系；
3. 对比三版的“03-例题”，判断哪一版最能帮助迁移和做题；
4. 对比三版的“04-自测”，判断哪一版既能保持形式特色，又不妨碍独立作答。

比较时可以重点记录：

- 哪一版最有阅读动力；
- 哪一版废话最少；
- 哪一版知识最清楚；
- 哪一版最容易记住；
- 哪些局部写法值得组合到最终风格中。
