# 参考答案

**老师：** 现在我们来核对。不要只看选项或结论，还要确认理由是不是落在正确的概念上。

## 客观题答案

### 1. B

**学生：** 磁盘文件是程序，两个运行实体是两个进程。系统给它们分配了不同 PID 和独立地址空间，说明它们是两个独立管理的运行实例。

### 2. A

**学生：** 程序计数器和 CPU 寄存器最直接支持现场恢复：前者记录接下来执行哪条指令，后者保存当前计算状态。

### 3. C

**学生：** 进程通常组织地址空间等资源，线程作为进程内的执行流接受 CPU 调度。

### 4. C

**学生：** 程序计数器、CPU 寄存器和线程栈由各线程分别保存，因为每条线程的执行位置、计算状态和函数调用过程都可能不同。

### 5. B

**学生：** 同进程线程切换通常更轻，因为地址空间和进程级资源可以继续沿用。不过程序计数器、寄存器和栈等线程现场仍要切换，所以开销不会消失。

## 场景简答参考

### 6. 下载器中的三条线程

**老师：** 三问分别对应共享、独立现场和共享冲突：

1. **可以直接访问共同数据。** 三条线程属于同一进程，通常共享地址空间、全局数据和堆。
2. **每条线程需要自己的执行现场。** 三条线程执行到不同指令，函数调用过程也不同，因此程序计数器和线程栈必须分别保存。
3. **可能产生竞态或数据不一致。** 多条线程的读写步骤相互穿插后，可能发生更新丢失，需要同步互斥机制协调。

### 7. 两种切换

**学生：** T1 切换到 T2 通常更轻。它们属于同一进程，可以沿用相同地址空间和进程级资源环境，重点切换线程现场。T2 切换到 Q 的线程跨了进程，还可能更换地址空间和内存管理上下文。两次切换都要保存旧现场、恢复新现场。
