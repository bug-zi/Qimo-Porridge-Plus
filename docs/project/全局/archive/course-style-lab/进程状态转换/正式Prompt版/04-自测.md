# 独立判断：三态与六种方向

午间订单记录已经交给你。请只依据进程是否占用 CPU、是否具备运行条件以及题干中的触发事件作答。完成全部题目后再查看文末答案。

## 一、单项选择题

### 1. 某进程没有占用 CPU，但除 CPU 外已具备继续执行所需条件，只等待调度。该进程处于（　）。

A. 运行态  
B. 就绪态  
C. 阻塞态  
D. 无法依据题干判断

### 2. 进程 P 正在运行，时间片用完后仍可继续执行。P 的状态变化是（　）。

A. 运行态 → 就绪态  
B. 运行态 → 阻塞态  
C. 就绪态 → 运行态  
D. 阻塞态 → 就绪态

### 3. 下列事件最典型地触发“运行态 → 阻塞态”的是（　）。

A. 调度程序选中进程并分配 CPU  
B. 进程时间片用完  
C. 运行进程请求磁盘 I/O，并等待完成  
D. 等待的 I/O 已经完成

### 4. 进程因等待键盘输入处于阻塞态。输入到达，进程被唤醒，但题干未说明它获得 CPU。此时应判断为（　）。

A. 阻塞态 → 运行态  
B. 阻塞态 → 就绪态  
C. 就绪态 → 运行态  
D. 就绪态 → 阻塞态

### 5. 关于基础三态模型中的直接转换，下列说法正确的是（　）。

A. 就绪进程可以不经运行便主动执行等待操作，直接进入阻塞态  
B. 阻塞事件完成后，进程必然立即进入运行态  
C. 被抢占的运行进程若仍可执行，通常进入就绪态  
D. 就绪进程只要具备运行条件，就已经占有 CPU

## 二、场景简答

### 6. 午间系统中，进程 P 初始处于就绪态。随后它被调度程序选中；运行中申请的打印机暂不可用；打印机可用后 P 被唤醒；稍后 P 再次被调度。请写出 P 的状态变化链，并为每条箭头写出触发原因。

### 7. 某同学画出两条箭头：“阻塞态 → 运行态”和“就绪态 → 阻塞态”，并认为它们都可以作为基础三态图中的常规直接转换。请分别说明这两条箭头为什么通常不能直接发生，并写出常规路径。

## 参考答案

### 单项选择题

1. **B。** 进程已具备运行条件但未占 CPU，只等待调度，属于就绪态。
2. **A。** 时间片用完使 P 失去 CPU，但题干说明它仍可执行，因此进入就绪态。
3. **C。** 请求磁盘 I/O 并等待会使运行进程暂时不具备继续运行条件，因此进入阻塞态。时间片用完通常对应运行态到就绪态。
4. **B。** 输入到达只解除阻塞原因，使进程重新具备运行条件；题干没有说明获得 CPU，因此先进入就绪态。
5. **C。** 被抢占只表示 CPU 被重新分配；若原进程仍具备运行条件，它回到就绪态。其余选项分别混淆了执行等待操作、事件完成与获得 CPU，以及具备运行条件与占用 CPU。

### 场景简答

6. **状态链为：就绪态 → 运行态 → 阻塞态 → 就绪态 → 运行态。** 第一次转换由调度程序选中并分配 CPU 触发；申请暂不可用的打印机使运行进程必须等待，触发运行态到阻塞态；打印机可用、进程被唤醒，使其恢复运行条件并进入就绪态；再次被调度并获得 CPU 后进入运行态。

7. **两条都通常不能作为直接转换。** 阻塞态中的进程在等待事件完成后只是恢复运行条件，通常先进入就绪态，再经过调度进入运行态，常规路径是“阻塞态 → 就绪态 → 运行态”。就绪态进程尚未占用 CPU，通常不能执行导致自己等待 I/O 或资源的操作；它要先被调度进入运行态，再因等待事件进入阻塞态，常规路径是“就绪态 → 运行态 → 阻塞态”。若题干对特殊过程有明确说明，应按题干给出的连续事件判断。
